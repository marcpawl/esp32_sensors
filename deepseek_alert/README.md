Python script to run on Linux Mint Xfce windows manager
on the host at startup to give notifications when the Deepseek
primetime is active, which impact the cost of using
the models.

It will create a window that will indicate the current
charge rate, and the schedule for charge rate changes.

You will need to have uv installed for the python
environment.

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

To have the program run automatically execute 
```
./install.sh
```
and reboot.
